Why we're here
We tested 492 pages: every URL in your sitemap, plus the Resources pages found on the site. No page reaches Google's recommended score on mobile yet, and in Google's mobile test the typical page takes about 9.5 seconds to show its main content.
This engagement starts with page speed, the foundation. On top of it we add the technical SEO and AEO layer, so search engines and AI tools can load and read every page correctly.
Please note
Scores move from test to test. Lighthouse results vary with device, network, and time of day, so we measure before and after with the same tool, the same settings, and the same number of runs.
Flag big site changes during the engagement. New scripts, apps, or page builds from other teams also change scores, so we log them alongside ours to keep the before/after clean.
Targets are agreed together. We confirm targets with your team at baseline sign-off, before any changes go live.

Common questions
Will the design of the site change?
No. We only work on code, scripts, assets, and page tags. The site looks exactly the same and loads faster.
How will we know what changed?
You get a PageSpeed before/after report using the same method as the baseline, plus a list of every fix that shipped.
How does this help the AEO metrics we track?
It gives every page a fast, correctly tagged base for your content and PR work to build on. Section 13 shows how each fix connects to each metric.
Who writes the new page titles and descriptions?
We build the system: every page gets its own title and description, with automatic fallbacks so nothing is ever blank. Custom wording stays with your team, editable in Sanity.

12 · Overall Impact
What changes for Vestwell.
A faster site is the first link in the chain. Each step makes the next one possible.
Faster, cleaner pages
Page speed fixes plus correct tags
Crawled more easily
Bots fetch and render more pages, and find new ones sooner
Understood correctly
One clear URL per page, labelled with what it is
Ready to be shown and cited
By Google search and AI answer engines
What you get
  • A faster site for every visitor. Every URL gets the speed pass, mobile first.
  • One clear URL per page. Canonicals stop pointing search engines at a redirect.
  • Pages labelled for Google and AI. Organization, WebSite, and Article schema, plus a title and description for every page.
  • New content found faster. The sitemap refreshes on its own, with dates, so new pages aren't missed for days.
  • A clear before/after for leadership. Same method as the baseline, so the comparison holds up.
  • A base your team can build on. Every page your content and PR teams publish lands on a fast, readable site.
