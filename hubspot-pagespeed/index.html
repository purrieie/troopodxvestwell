How we'll get there

01

Templates first

The 3 main templates (160 pages) are optimised first, then the 4 smaller ones (7 pages).

02

Faster main image

On phones, the main content takes 11.2 seconds on average. We compress and size the hero images correctly, and load them first.

03

Lighter scripts

Scripts block the page for 695ms on average. We load non-essential scripts after the page is ready. Tracking is not touched.

04

Faster first screen and a stable layout

Load only what the first screen needs, and reserve space for images, embeds and banners so the page doesn't jump.

05

Go-live and checks

Forms, links, redirects and tracking are tested before and after go-live, and every page is re-tested the same way.

Terms & notes
  1. Target: an average mobile score of 65 across all live campaign pages combined, measured the same way as today’s audit. It is an overall average, not a score for every individual page: some pages will land above 65 and some below.
  2. Score variation: PageSpeed scores change from run to run, usually by a few points. We report the average of 3 mobile runs per page.
  3. Measurement tool: scores are measured on Google PageSpeed Insights, mobile, unless stated otherwise.
  4. HubSpot limits: HubSpot’s own scripts can’t be removed; the target already allows for them.
  5. Change guidelines: a guideline doc will be shared for your team to follow on every future page and template change, so gains are not lost over time.
  6. Team dependency: the 15-day timeline needs prompt approvals from the Vestwell team, including the timing of changes to pages running A/B tests. Delays on approvals move the timeline by the same amount.
