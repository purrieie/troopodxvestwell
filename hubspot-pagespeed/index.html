Our Approach

Phase 01
01

Assess the templates

Map every campaign page to its HubSpot template, and find what slows each template down.

→
Phase 02
02

Optimise the templates, then hold the score

Fix each template once, so every page built on it gets faster. Tracking, forms and design stay exactly as they are.

How we'll get there

01

Template mapping

With Super Admin access, we list which template each page uses and assess them one by one.

02

Faster main image

On phones, the main content takes 11.2 seconds on average. We compress and size the hero images correctly, and load them first.

03

Lighter scripts

Scripts block the page for 695ms on average. We load non-essential scripts after the page is ready. Tracking is not touched.

04

Faster first screen and a stable layout

Load only what the first screen needs, and reserve space for images, embeds and banners so the page doesn't jump.

05

Go-live and checks

Forms, links, redirects and tracking are tested before and after go-live, and every page is re-tested the same way.

What we work on

We work at the template level, so improvements carry across every page built on it. The final list is agreed with your team before we start.

Terms & notes
  1. Target: an average mobile score of 65 across the live campaign pages, measured the same way as today's audit.
  2. Score variation: PageSpeed scores change from run to run, usually by a few points. We report the average of 3 mobile runs per page.

  4. HubSpot limits: HubSpot's own scripts can't be removed, so the exact plan per template is confirmed once we have access.
  5. Change guidelines: a guideline doc will be shared for your team to follow on every future page and template change, so gains are not lost over time.
  6. Team dependency: this engagement needs prompt access and approvals from the Vestwell team, starting with Super Admin access in HubSpot.
